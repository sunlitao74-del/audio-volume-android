# 音量调整

一个仅供个人使用的离线 Android 应用，用于调整 MP3 或 FLAC 文件的音量并另存为新文件。

## 特点

- 安装后完全离线运行，未申请联网权限
- 支持 MP3 与 FLAC 输入和同格式输出
- 可在 −18 dB 到 +18 dB 之间调整
- 使用 Android 系统文件选择器，无需申请整个存储空间权限
- 仅提供 arm64-v8a 版本，适用于绝大多数近年的 Android 手机

## 说明

MP3 输出需要重新编码；FLAC 输出仍为无损编码。增益过大时，原本接近满幅的音频可能产生削波失真。

## 构建

使用 Android Studio 打开项目并构建即可。项目要求 JDK 17、Android SDK 35 与 Build Tools 35.0.1。

仓库不包含签名密钥，也没有写死的 API Key、密码或令牌。发布 APK 时，请在本机或 CI 的安全变量中配置自己的签名信息，不要把密钥文件或密码提交到仓库。

音频处理使用 FFmpegKit Maintained 的 audio 构建，相关开源许可证文本会一并打包到 APK 中。
